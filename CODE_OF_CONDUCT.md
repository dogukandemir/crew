# Code of conduct

Be respectful, specific and constructive. Critique ideas and code without attacking people. Welcome contributors with different backgrounds and experience. Do not harass, threaten, discriminate, publish private information, or repeatedly derail discussions.

Maintainers may edit or remove harmful content, close discussions, or restrict participation. Enforcement should be proportionate and explain the behavior at issue. Report sensitive conduct concerns through a private maintainer contact; if none is listed, ask for one without posting the details publicly. Maintainers will avoid sharing reports beyond what is needed to address them.

This policy applies to repository issues, pull requests, discussions, and official project spaces.
